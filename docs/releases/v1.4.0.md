# v1.4.0 — Maintainable, provider-neutral foundation

This release turns the original single-file automation into a maintainable reference
implementation without changing its Apps Script deployment model.

## What changed

- Source code now lives in ordered modules under `src/`; `Code.gs` is a reproducible
  deployment bundle generated by `npm run build`.
- The default setup uses the generic webhook adapter, UTC, no assumed country code,
  and no internal notification recipient.
- Caller extraction can exclude service numbers and prefer a deployment-specific
  number pattern.
- A local simulator exercises voicemail, missed-call, and duplicate paths with
  synthetic data and no credentials.
- CI validates the bundle, offline tests, syntax, and public-repository safety on
  Node.js 20, 22, and 24.
- New configuration, operations, and decision records explain how to deploy and
  extend the project safely.

## Compatibility

The Modulus, Twilio, Telnyx, Vonage, and generic webhook adapters remain available.
Modulus is still optional: `configureModulusEmailPreset()` only applies its email
parsing defaults and does not select an SMS provider.

## Upgrade notes

Existing deployments can keep their current Script Properties. New deployments must
set `DEFAULT_COUNTRY_CODE` when local-format caller numbers are expected and choose an
SMS provider explicitly before enabling live sends.

Before deploying, run:

```bash
npm run validate
npm run demo -- all
```

Then follow the safe activation sequence in [Operations](../OPERATIONS.md).
